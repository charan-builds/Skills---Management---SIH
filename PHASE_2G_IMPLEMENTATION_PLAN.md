# PHASE 2G — CROSS-PORTAL UX INTEGRATION: IMPLEMENTATION PLAN

## 1. Job-vs-Benchmark Dependency Analysis
**Dependency Trace:**
- **Phase 2D `SkillGapService.calculate_skill_gaps`** retrieves the trainee's `target_role_id`.
- It calls **`FirestoreRepository.get_job(target_role_id)`** to fetch the benchmark data.
- It extracts the `skills_required` array from the returned job object.
- It iterates over these required skills to compare them against the trainee's `verified_skills` and `unverified_skills` to calculate `gap_size`, `priority`, and `evidence_state`.
- **Phase 2E `generate_recommendations`** directly relies on the gaps calculated by Phase 2D.
- **Data Seed Scripts** (`seed_extended_data.py`, `seed_demo_data.py`) populate the `jobs` collection with objects containing both legitimate benchmark data (`skills_required`) and forbidden ATS data (`min_salary`, `openings`, `employer_id`).

**Conclusion:** The `jobs` collection is currently masquerading as the benchmark data source. Deleting `jobs` without a replacement will break the `target_role` -> `Benchmark` -> `Skill Gap` -> `Upskilling Recommendation` pipeline.

## 3. Benchmark Source of Truth (Abstraction)
To preserve the intelligence pipeline while adhering to product boundaries, we will introduce the **`RoleBenchmark`** abstraction to replace the `jobs` collection.

**RoleBenchmark Schema:**
- `id`: (e.g., "BENCH_DATA_ANALYST_01")
- `title` / `role`: (e.g., "Data Analyst")
- `industry`: (e.g., "Information Technology")
- `skills_required`: Array of `{"skill_id": "...", "skill_name": "...", "required_level": 80, "importance": 0.9}`

It will **NOT** contain: `employer_id`, `employer_name`, `openings`, `min_salary`, `max_salary`, or `match`.

## 4. Recruitment Functionality to Remove
- **Frontend**: 
  - Delete `/jobs` and `/applications` routes/tabs in `TraineeDashboard.jsx`.
  - Delete `candidates` and `jobs` arrays in `EmployerDashboard.jsx` state.
  - Remove any UI elements related to job search, applying for jobs, or employers viewing candidate profiles.
- **Backend**:
  - Delete `app/routers/jobs.py` completely.
  - Remove `get_jobs` and candidate matching algorithms.
  - Update `seed_demo_data.py` and `seed_extended_data.py` to stop seeding vacancies and instead seed `role_benchmarks`.
