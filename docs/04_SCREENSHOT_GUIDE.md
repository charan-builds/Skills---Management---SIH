# Screenshot & Visual Documentation Guide

Visual evidence is critical for validating the Skilling Impact Intelligence platform. This document outlines the expected visual state of the application across various workflows.

> [!WARNING]
> **Screenshot Automation Limitation**: During this audit, the automated browser capture mechanism (Chrome CDP) experienced persistent WebSocket timeout errors (`30000ms exceeded`) in the deployment/build environment. As a result, automated screenshots could not be generated programmatically. 

However, the application is fully functional and can be visually verified by accessing the deployment directly. The following is a guide for human judges/reviewers on how to manually replicate the intended screenshot states.

## Target Directories

The `docs/screenshots/` directory has been created with the following subdirectories to organize visual assets if captured manually:
- `docs/screenshots/admin/`
- `docs/screenshots/trainee/`
- `docs/screenshots/employer/`
- `docs/screenshots/analytics/`
- `docs/screenshots/intelligence/`
- `docs/screenshots/authentication/`

## Manual Capture Walkthrough

To verify the platform's UI, navigate to the local or Vercel preview URL and perform the following actions:

### 1. Authentication
- **Target**: `01_login_page.png`
- **Action**: Navigate to `/login`.
- **Expected State**: A clean authentication portal presenting distinct login paths for Admin, Trainee, and Employer roles.

### 2. Admin Dashboard & Filters
- **Target**: `02_admin_dashboard_initial.png`, `03_admin_dashboard_filtered.png`
- **Action**: Login as Admin. Observe the initial state at `/admin/dashboard`. Then, change the "District" and "Programme" dropdowns.
- **Expected State**: The KPI cards (Total Trainees, Placed) and funnel charts should dynamically rerender to reflect the filtered dataset.

### 3. Impact Intelligence
- **Target**: `04_impact_intelligence.png`
- **Action**: Navigate to `/admin/intelligence`.
- **Expected State**: You should see AI-generated Priority Risk Scores (e.g., High Risk for specific cohorts) and actionable recommendations generated by the backend decision engine.

### 4. Trainee Management
- **Target**: `05_trainee_list.png`, `06_trainee_profile.png`
- **Action**: Navigate to `/admin/trainees`. Click on a trainee's "View Profile" button.
- **Expected State**: A comprehensive data grid of all trainees, transitioning into a detailed view of a specific trainee's demographics and skill matrix.

### 5. Trainee Portal
- **Target**: `07_trainee_dashboard.png`, `08_explore_jobs.png`
- **Action**: Logout, and login as a Trainee. Navigate to `/trainee/explore`.
- **Expected State**: The UI should shift to a personalized job board showing open requisitions ranked by an AI-computed "Match %".

### 6. Employer Portal
- **Target**: `09_employer_candidates.png`
- **Action**: Logout, and login as an Employer. Navigate to `/employer/candidates`.
- **Expected State**: A talent sourcing board displaying trainees who possess the skills required by the employer's open jobs, sorted by match relevance.
